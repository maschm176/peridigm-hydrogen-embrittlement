# fragmenting_cylinder/figures/velocity_bc

Figures for the velocity-loaded cylinder runs (4-point mesh, horizon 4.17 mm, 10% jitter,
1.5% angular loading perturbation, 1.1x velocity; HE_0 / HE_30 / HE_60).
Source runs: `../imperfection_test/HE{0,30,60}_4pt_dsmall_jit10_load/*.e` (see memory
note "Cylinder best config" for all settings).

| File | What |
|---|---|
| `compute_thirds_data.py` | Reads the three merged .e files, writes `dsmall_thirds_data.json` (slow, ~minutes) |
| `dsmall_thirds_data.json` | Numbers behind the figure + table: whole-cylinder mean broken fraction, [bottom, middle, top] thirds, 3 largest pieces, final time |
| `plot_thirds.py` | Draws the figure from the JSON. All colors/sizes/title are in the STYLE block at the top |
| `broken_fraction_thirds_dsmall_jit10.png` | Output figure |

To tweak the look: edit the STYLE block in `plot_thirds.py`, then `python3 figures/velocity_bc/plot_thirds.py`
(takes a second, no simulation data needed). To refresh the numbers for other runs: edit the file
paths in `compute_thirds_data.py` and run it from the `fragmenting_cylinder/` directory.

Definitions: "broken-bond fraction" = Broken_Bond_Volume_Averaged at the last frame, averaged over
the points in each third of the *reference* height. "Pieces" = connected groups of surviving points
(Weighted_Volume > 0) linked within 1.5x spacing in the deformed configuration.

## Fragment-size histograms
| File | What |
|---|---|
| `compute_fragment_sizes.py` | For each HE level, at 1/3, 2/3 and the end of the run: list of fragment sizes (points) -> `fragment_sizes.json` (slow) |
| `plot_fragment_hist.py` | Grid (rows = time, columns = HE level). `python3 figures/velocity_bc/plot_fragment_hist.py` -> `fragment_size_hist.png` (number of fragments per size class, log y). `MODE=mass python3 figures/velocity_bc/plot_fragment_hist.py` -> `fragment_mass_hist.png` (% of all points in each size class). Size classes, colors, fonts: STYLE block at the top |
Fragment = connected group of surviving points (Weighted_Volume > 0) within 1.5x spacing in the deformed shape; points with Weighted_Volume = 0 count as size-1 "dust". Frames: 1/3, 2/3 and last of 212 output frames (t = 83, 167, 250 us).

## Cumulative fragment-size plots
`plot_fragment_cdf.py` (reads `fragment_sizes.json`; style block at top) writes
`fragment_size_ccdf.png` (fraction of fragments with size >= s, log-log, one panel per time, one curve per HE level) and
`fragment_mass_cdf.png` (share of all points sitting in fragments of size <= s). Run: `python3 figures/velocity_bc/plot_fragment_cdf.py`.
`plot_fragment_cdf.py` also writes single-panel versions: `fragment_size_ccdf_2of3.png`, `fragment_size_ccdf_end.png`,
`fragment_mass_cdf_2of3.png`, `fragment_mass_cdf_end.png` (size set by `FIGSIZE_SINGLE`).

## Grouped histograms (one figure per time, HE levels side by side within each size class)
`plot_fragment_hist_grouped.py` -> `fragment_hist_grouped_{1of3,2of3,end}.png` (number of fragments, log y);
`MODE=mass python3 figures/velocity_bc/plot_fragment_hist_grouped.py` -> `fragment_mass_grouped_{1of3,2of3,end}.png` (% of points).

## Mass-weighted views (share of material by fragment size)
`fragment_mass_hist.png`, `fragment_mass_grouped_*.png` and `fragment_mass_cdf*.png` weight every fragment by its size
(height = sum of fragment sizes = number of points in that class). `plot_fragment_mass_stacked.py` -> `fragment_mass_stacked.png`
draws each concentration as one 100% bar split by fragment-size class, one panel per time.

## Quick guide: restyling `fragment_mass_stacked.png`
Edit the STYLE block at the top of `plot_fragment_mass_stacked.py`, then run `python3 figures/velocity_bc/plot_fragment_mass_stacked.py` (~1 s, no simulation data needed):
- `CLASSES` -- size-class edges and legend labels (e.g. split the "≥10k" class into 10k-20k and ≥20k; keep `CLASS_COLORS` the same length)
- `CLASS_COLORS` -- one color per class, smallest fragments first
- `MIN_LABEL_PCT` -- hide % labels on segments thinner than this
- `BG`, `TEXT`, `MUTED`, `FIGSIZE`, `DPI` -- background, text colors, size, resolution
Title, legend title and bar order are in the body of the script (look for `suptitle`, `fig.legend`, `(0, 30, 60)`).
Everything reads `fragment_sizes.json`; to change which frames are shown (currently 1/3, 2/3, end) edit `FRACS` in
`compute_fragment_sizes.py` and re-run it from `fragmenting_cylinder/` (a few minutes), plus the `TIMES` list in the plot scripts.
`plot_fragment_mass_stacked.py` also writes `fragment_mass_stacked_end.png` (end-of-run panel only; size set by `FIGSIZE_SINGLE`).

## Damage-level stacked bars (velocity BC)
`compute_damage_classes.py` (run from `fragmenting_cylinder/`) -> `damage_classes.json`: counts of points per damage class at 1/3, 2/3, end, for
D = "Damage" (accumulated Brozzo damage) and B = Broken_Bond_Volume_Averaged. `plot_damage_classes_stacked.py` -> `damage_classes_stacked_end.png`
(`TIME=0.667` -> `_2of3`, `TIME=0.333` -> `_1of3`). Left panel D, right panel B; bold number over each bar = share of points above 0.5.
Classes (EDGES in the compute script, CLASS_LABELS / CLASS_COLORS in the plot script): <0.25, 0.25-0.5, 0.5-0.75, 0.75-0.9, >=0.9.
Finding: share above 0.5 is similar for D (75/76/82%) but strongly separated for B (17/43/72%) -- embrittlement shows up in broken bonds, not in accumulated D.
